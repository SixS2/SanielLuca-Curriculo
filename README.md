# 📄 Currículo Web & Portfólio Inicial

Página de currículo online responsiva e minimalista, desenvolvida como trabalho prático no **1.º semestre da faculdade** para consolidar os fundamentos essenciais de desenvolvimento web front-end.

---

## 🎯 Sobre o Projeto

O projeto surgiu a partir de uma proposta académica no início do curso universitário, com o intuito de aplicar na prática os conceitos básicos de estruturação de interfaces e folhas de estilo para a web.

A ideia foi transformar o modelo clássico de currículo em PDF numa página interativa e acessível via navegador, servindo tanto como exercício de aprendizagem quanto como uma apresentação inicial da trajetória, competências técnicas e ligações profissionais.

### ✨ O que foi trabalhado

- **Fundamentos Web Sólidos:** Prática de marcação HTML5 semântica e estilização pura com CSS3, sem recorrer a frameworks prontos.
- **Responsividade:** Ajuste de layout e elementos para garantir boa legibilidade tanto no telemóvel quanto no computador.
- **Integração de Links:** Navegação rápida com atalhos visuais para GitHub, LinkedIn e redes de contacto.
- **Performance e Simplicidade:** Código leve, de carregamento instantâneo e focado em clareza de conteúdo.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura e semântica do documento.
- **CSS3:** Estilização visual, tipografia, espaçamentos e media queries para adaptação de ecrãs.
- **SVGs / Ícones:** Recursos visuais para hiperligações externas e redes sociais.
